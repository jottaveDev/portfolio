# João Victor Alves - Portfólio

Seja bem-vindo ao meu portfólio! Este site foi desenvolvido com o objetivo de me apresentar, compartilhar meus projetos e demonstrar as habilidades que possuo na área de desenvolvimento. Em breve, planejo adicionar uma seção com artigos e tutoriais criados por mim, para compartilhar meu conhecimento com a comunidade.

### Tecnologias utilizadas

- Astro.js: framework para construção de sites rápidos e otimizado para SEO.
- TailwindCSS: framework CSS para desenvolvimento de interfaces responsivas e customizáveis.
